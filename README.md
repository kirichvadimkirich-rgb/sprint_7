
Данный проект содержит автоматизированные API-тесты для сервиса Доставка самоката (https://qa-scooter.praktikum-services.ru/).  
Документация API (https://qa-scooter.praktikum-services.ru/docs/)

Тесты покрывают основные ручки API в соответствии с учебным заданием.
1. Создание курьера
курьера можно создать;
нельзя создать двух одинаковых курьеров;
чтобы создать курьера, нужно передать в ручку все обязательные поля;
запрос возвращает правильный код ответа;
успешный запрос возвращает {"ok":true};
если одного из полей нет, запрос возвращает ошибку;
если создать пользователя с логином, который уже есть, возвращается ошибка.
2. Логин курьера
курьер может авторизоваться;
для авторизации нужно передать все обязательные поля;
система вернёт ошибку, если неправильно указать логин или пароль;
если какого-то поля нет, запрос возвращает ошибку;
если авторизоваться под несуществующим пользователем, запрос возвращает ошибку;
успешный запрос возвращает id.
3. Создание заказа
Проверки, что, когда создаёшь заказ:
можно указать один из цветов — BLACK или GREY;
можно указать оба цвета;
можно совсем не указывать цвет;
тело ответа содержит track.
4. Список заказов
Проверь, что в тело ответа возвращается список заказов.


Требования к окружению
Установленный Python версии 3.8 или выше.
Установленные зависимости из `requirements.txt`
Чтобы запустить Allure, нужна среда разработки Java. Установка JDK

Установить в vs code (терминал):
Установка pytest
pip install pytest
Установка requests 
pip install requests 
Установка allure
pip install allure-pytest

Запуск тестов
pytest -v tests/ --alluredir=allure_results

Теперь нужно сформировать отчёт в формате веб-страницы. Напиши в терминале Vs Code:
allure serve allure_results

Сформируется HTML-файл: по умолчанию он будет лежать в директории с установленным Allure. Запустится веб-сервер Allure, и в браузере откроется вкладка с результатами тестов.


Файл с внешними зависимостями
Создать файл requirements.txt Этот файл — список внешних зависимостей.Обычно команду выполняют перед отправкой кода в репозиторий.
Если при доработке проекта появился новый импорт, используй команду снова. Она обновит файл.
pip freeze > requirements.txt


Как установить зависимости из файла
pip install -r requirements.txt

** 
Тесты используют фикстуры с автоматической очисткой (teardown) – созданные курьеры удаляются после каждого теста.

В Allure-отчётах отображаются шаги, прикреплённые JSON-тела запросов и ответов, что упрощает отладку.
